# Primal Studio · instaladores

Aqui ficam só os instaladores do Primal Studio. Para baixar, use a página de
download do Studio.

- **Mac** com chip Apple: `PrimalStudio-<versão>-mac-arm64.dmg`
- **Windows** 10 e 11, 64 bits: `PrimalStudio-<versão>-windows-x64-setup.exe`

Cada versão traz o `SHA256SUMS.txt` para conferir o arquivo baixado:

- Mac: `shasum -a 256 PrimalStudio-<versão>-mac-arm64.dmg`
- Windows (PowerShell): `Get-FileHash .\PrimalStudio-<versão>-windows-x64-setup.exe`
